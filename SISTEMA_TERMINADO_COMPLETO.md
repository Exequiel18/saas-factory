## ⚠️ SOLO FALTA (5 MIN)

### Configurar Webhook de Mercado Pago

**Ve a:**
```
https://saas-factory-antigravity.vercel.app/dashboard/deploy
```

**Seguí los pasos en la sección "🔧 Configurar Webhook de Mercado Pago":**

1. **Copiá la URL del webhook:**
   ```
   https://saas-factory-antigravity.vercel.app/api/mercadopago/webhook
   ```

2. **Configurá en Mercado Pago:**
   - Ve a: https://www.mercadopago.com.ar/developers/panel
   - Webhooks → Crear
   - Pegá la URL
   - Eventos: `payment.created`, `payment.updated`
   - Crear
   - **Copiá el secret**

3. **Agregalo a Vercel:**
   - Ve a: https://vercel.com/dashboard
   - Click en: `saas-factory-antigravity`
   - Settings → Environment Variables
   - Add New
   - Key: `MERCADO_PAGO_WEBHOOK_SECRET`
   - Value: (el secret que copiaste)
   - Seleccioná: Production, Preview, Development
   - Save
