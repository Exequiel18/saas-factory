# 🚀 DEPLOY MANUAL EN VERCEL

> **Hacer deploy manual para ver los cambios nuevos**

---

## 🎯 PASOS (2 minutos)

### 1. Ir a Vercel Dashboard

Abrí: https://vercel.com/dashboard

### 2. Seleccionar Proyecto

Click en: `saas-factory-antigravity`

### 3. Hacer Redeploy

1. Ve a la pestaña **Deployments**
2. Buscá el último deploy
3. Click en los **3 puntos** (⋯) del último deploy
4. Click en **"Redeploy"**

### 4. Esperar

Esperá 2-3 minutos mientras Vercel hace el build.

### 5. Ver Resultado

Cuando termine, abrí:
**https://saas-factory-antigravity.vercel.app**

## 🔄 ALTERNATIVA: Cambiar Rama

Si querés usar la rama nueva `main-clean`:

1. Vercel Dashboard → `saas-factory-antigravity`

3. Change Branch → `main-clean`
4. Save
5. Vercel hará deploy automático
