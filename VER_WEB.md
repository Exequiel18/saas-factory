## 🚀 OPCIÓN 1: LOCAL (Desarrollo)

### Iniciar el servidor local:

```bash
npm run dev
```

Luego abrí en tu navegador:
- **Landing:** http://localhost:3000
- **Chequeo:** http://localhost:3000/chequeo-real

---

## 🌍 OPCIÓN 2: PRODUCCIÓN (Vercel)

Si el deploy ya terminó, abrí:

- **Landing:** https://saas-factory-antigravity.vercel.app
- **Chequeo:** https://saas-factory-antigravity.vercel.app/chequeo-real

### Verificar estado del deploy:

1. Ve a: https://vercel.com/dashboard
2. Click en: `saas-factory-antigravity`
3. Ve a la pestaña **Deployments**
4. Si está en verde (Ready) → Ya está online
