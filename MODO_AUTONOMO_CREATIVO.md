## 🚧 BARANDAS DE SEGURIDAD (NO NEGOCIABLES)

### 1️⃣ TODO LO NUEVO ES "EXPERIMENTAL"

Toda nueva feature debe nacer como:

- `experimental = true`
- Fuera del score principal
- Sin afectar pagos, upsells ni estados

**Primero observa.**
**Después decide si se integra.**

### 2️⃣ NUNCA ROMPER EL LOOP DE DINERO

El loop base:
```
Evaluar → Score → Alerta → Upsell → Acción → Retención
```

Cualquier cosa nueva:
- ❌ No puede interrumpir este loop
- ❌ No puede ralentizarlo
- ❌ No puede confundirlo

**Si interfiere → se desacopla.**

### 3️⃣ CAMBIOS GRADUALES, NO RADICALES

**Prohibido:**
- ❌ Refactors masivos
- ❌ Reescrituras totales
- ❌ Cambios de paradigma sin datos

**Permitido:**
- ✅ Capas nuevas
- ✅ Módulos paralelos
- ✅ Flags
- ✅ Pesos configurables
- ✅ A/B internos silenciosos

### 4️⃣ AUTONOMÍA CON MEMORIA

El sistema debe:
- ✅ Registrar qué creó
- ✅ Por qué lo creó
- ✅ Qué impacto tuvo

**Nada creativo sin logging.**
**La creatividad sin memoria es ruido.**

### 5️⃣ INTUICIÓN GUIADA POR DATOS

El sistema puede intuir, pero debe validar:

- Si una idea no mejora ingresos o retención → se degrada
- Si mejora métricas críticas → se promueve
- Si no tiene impacto → se archiva

**No eliminar rápido.**
**Primero observar.**

## 📊 SISTEMAS IMPLEMENTADOS

### 1. Sistema de Experimentación (`lib/experimental-system.ts`)
- Crea experimentos con `experimental = true`
- Evalúa impacto basado en datos
- Promueve a core solo si cumple criterios
- Archiva si no tiene impacto

### 2. Protección del Core (`lib/core-protection.ts`)
- Define componentes core protegidos
- Verifica impacto antes de cambios
- Ejecuta fallback si core se rompe
- Verifica integridad periódicamente

### 3. Creador Autónomo (`lib/autonomous-creator.ts`)
- Crea ideas/productos/features autónomamente
- Verifica que no afecte core antes de crear
- Evalúa creaciones periódicamente
- Loggea todo para memoria

### 4. API de Evaluación (`app/api/autonomous/evaluate/route.ts`)
- Evalúa experimentos activos
- Decide promover/archivar/pausar
- Verifica integridad del core
