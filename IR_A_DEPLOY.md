---

## 📋 QUÉ HACER

### 1. Abrir la Página

Ve a: **`/dashboard/deploy`**

O desde el dashboard principal, click en **"🚀 Deploy Automático"**

### 2. Obtener Tokens

#### GitHub Token:
1. https://github.com/settings/tokens
2. "Generate new token (classic)"
3. Scope: `repo`
4. Copiá el token

#### Vercel Token:
1. https://vercel.com/account/tokens
2. "Create Token"
3. Scope: Full Access
4. Copiá el token

### 3. Ingresar en la Página

1. Pegá los tokens en los campos
2. (Opcional) Nombre del repo
3. Click "Deploy Automático Completo"

### 4. Esperar

El sistema hace TODO automáticamente:
- ✅ Crea repo en GitHub
- ✅ Sube código
- ✅ Configura Vercel
- ✅ Hace deploy
- ✅ Te da la URL
