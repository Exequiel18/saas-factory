## 🚀 CÓMO SACARLO ONLINE

### Opción 1: Script Automático (Recomendado)

```bash
npm run deploy:todo
```

El script hace TODO y te dice qué hacer después.

### Opción 2: Dashboard

1. Ve a `/dashboard/deploy`
2. Dá permisos (tokens)
3. Click "Deploy Automático"
4. El agente hace todo

### Opción 3: Manual

1. Ve a https://vercel.com
2. Importá tu repo
3. Configurá variables
4. Deploy
