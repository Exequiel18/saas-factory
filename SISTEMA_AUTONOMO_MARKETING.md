# 🧠 SISTEMA AUTÓNOMO DE MARKETING

> **El sistema es más inteligente que vos. Decide qué, cuándo y dónde postear. Vos solo aprobás o dejás que funcione solo.**

## 🎯 CÓMO FUNCIONA

### 1️⃣ El Sistema Piensa por Vos

**Qué hace:**
- Analiza qué contenido funciona mejor
- Decide cuándo postear (mejor día y hora)
- Elige la plataforma óptima
- Genera contenido automáticamente
- Te da recomendaciones inteligentes

**Vos:**
- Solo aprobás las acciones
- O dejás que funcione solo

---

### 2️⃣ Dashboard Autónomo

**Ruta:** `/dashboard/autonomous-marketing`

**Qué ves:**
- Plan semanal generado automáticamente
- Recomendaciones del sistema
- Análisis de performance
- Acciones listas para aprobar

**Qué hacés:**
- Aprobás las que te gustan
- Editás las que querés cambiar
- Descartás las que no te sirven

---

### 3️⃣ El Sistema Aprende Solo

**Cómo:**
- Registra qué contenido convierte más
- Aprende qué horarios funcionan mejor
- Identifica qué plataforma da mejores resultados
- Optimiza automáticamente

**Resultado:**
- Cada semana es más inteligente
- Menos trabajo para vos
- Mejores resultados

## 🚀 CÓMO USARLO

### Opción 1: Dashboard (Recomendado)

1. Ve a `/dashboard/autonomous-marketing`
2. Revisá el plan generado
3. Aprobá las acciones que te gustan
4. Editá las que querés cambiar
5. Descartá las que no te sirven

### Opción 2: Script Automático

```bash
node scripts/autonomous-marketing-executor.js
```

Esto genera el plan y te lo muestra en consola.

### Opción 3: API Directa

```bash
curl http://localhost:3000/api/autonomous-marketing/plan
```
