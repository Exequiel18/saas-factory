# 🚀 ACTUALIZAR VERCEL - 3 PASOS

> **Solución simple para actualizar la web en Vercel**

---

## 📋 PASOS (2 MINUTOS)

### 1. Ve a Vercel Dashboard
```
https://vercel.com/dashboard
```

### 2. Click en el Proyecto
```
saas-factory-antigravity
```

### 3. Cambiá el Branch
- **Settings → Git**
- **Production Branch:** Cambiá de `main` a `nuevo-diseno`
- **Save**

### 4. Redeploy
- **Deployments →** Click en el último
- **Redeploy**

---

## ⏳ ESPERÁ 2-3 MINUTOS

Cuando termine el build, la web en:

```
https://saas-factory-antigravity.vercel.app/
```

Mostrará el nuevo diseño.

---

**Eso es todo. 3 pasos y en 2-3 minutos está listo. 🚀**
